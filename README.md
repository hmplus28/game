# Ludo Arena

Ludo Arena یک تجربهٔ منچ رقابتی با رابط فارسی راست‌به‌چپ است. رابط کاربری با React، TypeScript و Tailwind ساخته شده و سرویس Django جداگانه، APIهای اولیهٔ تاس، ثبت حرکت و وضعیت اتاق را ارائه می‌دهد.

## قابلیت‌های اصلی

| بخش | وضعیت |
| --- | --- |
| داشبورد و صفحات گیمینگ RTL | آماده |
| تاس با انیمیشن پرتاب و توقف | آماده |
| حرکت مرحله‌ای و هایلایت مسیر مهره | آماده |
| چیدمان واکنش‌گرا برای دسکتاپ، تبلت و موبایل | آماده |
| Django API برای تاس، حرکت و اتاق بازی | آماده |
| حالت چندنفرهٔ هم‌زمان و احراز هویت عملیاتی | مرحلهٔ بعد |

## اجرای رابط کاربری

```bash
pnpm install
pnpm dev
```

## اجرای API جنگو

```bash
cd django_backend
python3 -m pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py runserver
```

برای اتصال رابط به سرویس Django، متغیر محیطی `VITE_DJANGO_API_URL` را برابر URL ریشهٔ API قرار دهید. بدون این مقدار، رابط برای پیش‌نمایش بصری از رفتار محلی استفاده می‌کند.

> برای محصول عملیاتی، کلید محرمانه، میزبان‌های مجاز، CORS محدود، پایگاه دادهٔ پایدار، احراز هویت و کانال بلادرنگ باید با متغیرهای محیطی و زیرساخت مناسب پیکربندی شوند.
